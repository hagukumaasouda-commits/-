# 離脱理由の修正・物販在庫の入出庫記録 仕様書 v2

## 1. 離脱理由の修正

これまで「離脱を記録する」操作で入力した離脱理由・補足メモは、作成後に修正する手段が無かった。離脱記録カードに「理由を修正する」の折りたたみフォームを追加し、`reason`・`reasonNote`のみを修正できるようにした(確認日・自動生成されたフォローアップチェックポイントには影響しない)。

## 2. 物販在庫の入出庫記録

### 背景
これまで`ProductStockIn`(仕入れ記録)は「仕入れ(入荷)」専用で、在庫が減る操作(他店舗への移動)や、実在庫とのズレを直接補正する手段が無かった。

### 設計

`ProductStockIn`に`type`(`ProductStockMovementType`: `PURCHASE`仕入れ / `TRANSFER_OUT`他店舗へ移動 / `ADJUSTMENT`棚卸調整)を追加し、「入出庫記録」として扱う。`quantity`は符号付きの値として保存する(仕入れ=正、他店舗への移動=負、棚卸調整=正負どちらも)。既存データはすべて`PURCHASE`として扱う(後方互換)。

現在庫の計算式を「仕入れ数量の合計 - 販売数量の合計」から「入出庫数量(符号付き)の合計 - 販売数量の合計」に変更する。既存の仕入れのみのデータでは計算結果は変わらない。

### 入力UI(3種類をラジオボタンで切り替え、既存の紹介元入力方式と同じpeer-checkedパターンで表示項目を切り替える)

- **仕入れ**: 数量(1以上)
- **他店舗へ移動**: 数量(1以上、渡した数)+ 移動先(自由記述、プレースホルダ「砥部院 など」)。保存時にDB上は負の数量として記録する
- **棚卸調整**: 現在の実在庫数(0以上、実際に数えた数)。保存時に「入力値 - 現時点の計算上の在庫」を差分として記録する

共通項目: 日付・担当スタッフ・メモ(任意)

### 編集・削除

- 仕入れ・他店舗への移動は、作成時と同じ項目(数量・移動先・日付・担当・メモ)をそのまま修正できる
- 棚卸調整は、差分(quantity)の再計算が「その時点の在庫」に依存し事後の整合性が取りにくいため、日付・担当・メモのみ修正可能とし、差分自体は固定する(数値を直したい場合は削除して棚卸調整を再登録する運用とする)
- 削除はいずれの種類でも可能(既存の仕入れ削除と同じ)

### 一覧表示

在庫管理ページの「現在の在庫」表に、仕入れ累計・他店舗移動累計・調整累計・販売累計・現在庫を表示する。履歴一覧(旧「仕入れ履歴」)は「入出庫履歴」に改め、種別・移動先を表示する。
