# 基本検査記録・見立てカンペ 仕様書 v2

元仕様: アップロードされた「基本検査記録・見立てカンペ 仕様書 v1」。実装にあたっての設計判断を記録する。

## 1. データ保存方式

- `ChartRecord`に立位・座位・背臥位それぞれ1つずつ、`standingExam Json?` / `sittingExam Json?` / `supineExam Json?` を追加する。
- 既存の`exam Json?`フィールド(コメント「可動域・脊椎状態・重心軸などの検査値」)は`prisma/seed.ts`のダミーデータ以外どこからも参照されておらず、実質未使用だった。本仕様が実装する内容そのものなので、`exam`フィールドは削除し3つの新フィールドに置き換える(データ移行対象なし、本番でも未使用のため安全)。
- `treatmentDetail Json?`(部位×体位×コメントの施術詳細)は本仕様のスコープ外のため触らない。
- 各Jsonの中身は自由記述メモを含む全項目を1オブジェクトにまとめる(生活習慣サポート実施状況などと同様の方式)。空欄の項目もキー自体は存在させ`null`/`false`/`[]`で保持する。

## 2. 選択肢の型

- 複数選択タグ(「捻じれ/膨隆/中心軸逸脱」「スプリング/頸部屈曲伸展/左右回旋/左右側屈」など): 文字列配列。既存の`TagCheckboxes`コンポーネントをそのまま再利用。
- 3段階タグ(特記なし/軽度/著明): 新規`TriStateRadio`コンポーネント(ラジオボタン)。値は`"NONE" | "MILD" | "MARKED"`。
- 有無・二択(トランズ、膝窩の滞りなど): 新規`YesNoRadio`コンポーネント。値は`"YES" | "NO"`。
- 三点アーチ(使えている/使えていない)・重心軸(正常/逸脱)は項目ごとにラベルが違う二択のため、`YesNoRadio`にカスタムラベルを渡せるようにする。
- 筋緊張部位は既存の`BODY_PART_TAGS`を流用(仕様書の指定通り)。
- センダン所見のチェックボックスは、CSSの`peer`/`peer-checked`パターン(既存の紹介元入力方式で使用済み)でJSなしにヒント文を表示する。

## 3. UI配置

- 来院記録フォームに「基本検査記録」の折りたたみ`<details>`ブロックを新設。中に立位・座位・背臥位のサブセクション(それぞれ`<details>`または見出し+フィールド群)を配置。
- 見立てカンペは評価欄(`evaluation`)の直前に、折りたたみ`<details>`として常設。編集不可の静的な参照テキスト。
- 見立てカンペの内容(陰陽10秒判断、気血津液弁証、臓腑弁証、基本検査と見立てフレームの対応表)は静的コンポーネントとして`lib/mitate-cheatsheet.tsx`に実装し、一般的な東洋医学の教科書的内容に基づいて記述する(スタッフ向け参照資料であり、患者への自動診断機能ではない)。

## 4. 顧客詳細ページ(タイムライン)への表示

- 仕様書には来院記録フォームへの入力機能のみが明記されているが、既存のカルテ項目(主訴タグ・部位タグ・生活習慣サポート等)は全てタイムラインにも表示される慣習があるため、一貫性のため基本検査記録もタイムラインに表示する。
- ただし全項目を常に表示すると1来院あたりの表示量が大きく増えるため、来院タイムラインの各行に「基本検査記録を見る」の折りたたみ`<details>`を追加し、記録がある体位のみ・記録がある項目のみを表示する(全項目未入力ならこの折りたたみ自体を表示しない)。

## 5. 実装対象外・保留

- センダン所見チェック時の「施術方針欄に...ヒントを表示する」は、既存フォームに独立した「施術方針欄」が無いため、来院記録フォームの基本検査記録セクション内(センダンのチェックボックスのすぐ下)にヒント文を表示する形で実装する。
- 気づきチェック(見立ての深さ観点)との連携は本仕様のスコープ外(v1の2.4節記載の通り)。
