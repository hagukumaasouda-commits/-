# 必要来院ペース確定・回復度/口コミ/紹介欄 仕様書 v2

アップロードされたv1(Markdown、リポジトリ外)を受けての実装用整理。v1からの変更点は **[v2で変更]** として明示する。

## 1. 必要来院ペース(選択肢の確定・修正)

`docs/departure-followup-spec-v2.md`の`VisitInterval`enum(2.1節)を、既存の顧客管理シートに合わせた8段階に置き換える。**詳細・旧値からの移行対応表はそちらのドキュメントに直接上書き済み**なので、本書では重複させない。

離脱検知ロジック(経過日数 > 必要来院ペースの日数 × 3)に変更はない。

## 2. 回復度(健康度幸福度)

**[v2で確認] 既存の`ClientStatusSnapshot.healthScore`との関係**: `schema.prisma`には週次/月次スナップショット用に`ClientStatusSnapshot.healthScore`(Int、連続値の%)が既に定義されているが、実際にはどの画面・処理からも読み書きされていない未使用フィールドだった(`isActive`が離脱フォロー機能を実装するまで未使用だったのと同様の状態)。今回追加する「回復度」は来院ごとに入力する離散選択(7段階のバケット)であり、粒度も用途も別物なので、`ClientStatusSnapshot`には触れず`ChartRecord`に新規フィールドとして追加する。将来的にスナップショット集計を作る際に、この値を積み上げ元にする可能性はあるが、今回はスコープ外。

### 2.1 データモデル(`ChartRecord`)

```prisma
enum HealthHappinessScore {
  ABOVE_80 // 80%以上
  PCT_70   // 70%
  PCT_60   // 60%
  PCT_55   // 55%
  PCT_50   // 50%
  PCT_40   // 40%
  BELOW_40 // 40%以下
}
```

| フィールド名 | 型 | 説明 |
|---|---|---|
| `healthHappinessScore` | `HealthHappinessScore?` | 回復度(健康度幸福度)。任意項目 |

### 2.2 UI要件

- 来院記録フォームに追加。任意項目(必須にしない)
- 顧客詳細ページの「基本情報」に、直近の来院の値を表示する(`requiredVisitInterval`と同じ「最新値表示」の扱い)

## 3. 口コミ・紹介

### 3.1 データモデル(`ChartRecord`)

| フィールド名 | 型 | 説明 |
|---|---|---|
| `testimonialObtained` | `Boolean`(既定false) | 口コミを取得したか |
| `testimonialObtainedDate` | `DateTime?` | 取得日(任意) |
| `referralGiven` | `Boolean`(既定false) | 紹介をしてくれたか |
| `referralCount` | `Int?` | 紹介人数(任意。未入力かつ`referralGiven=true`の場合はサーバー側で1として扱う) |

### 3.2 UI要件

- 来院記録フォームに追加。チェックボックスで、チェックした場合のみ付随情報(取得日・人数)の入力欄を表示する(JS不要、CSSの`:has()`で表示切り替え)
- 来院タイムラインに、口コミ取得・紹介ありの来院を表示する

### 3.3 将来の拡張(今回は実装しない)

v1の記載通り、月次・スタッフ別の紹介数・口コミ数集計は将来対応。今回はデータの記録のみ。

## 4. 一括インポートCSVへの影響

**[v3で撤回]** 一度`/clients/import`としてCSV一括インポート機能を実装したが、旧顧客管理シートのデータが不完全なため撤去した。既存顧客の来院回数・ランク・必要来院ペースは、顧客登録・編集画面およびカルテ記録画面からの手動入力のみで対応する方針に変更(`docs/client-import-spec-v2.md`は削除済み)。
