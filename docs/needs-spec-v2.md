# 顕在ニーズ・深層ニーズ・ウォンツ 仕様書 v2

アップロードされた v1 仕様書(`顕在ニーズ・深層ニーズ・ウォンツ_仕様書_v1.md`)をそのまま実装した。v1からの変更点は無いが、実装時に決めた詳細を記録する。

## 1. データモデル

`Client`に3フィールドを追加(`prisma/schema.prisma`)。`medicalHistory`・`familyData`・`personalData`と同じ性質(顧客単位・自由記述・通院の中で更新されうる)として扱う。

| フィールド | 説明 |
|---|---|
| `manifestNeed` | 顕在ニーズ(今困っていること) |
| `deepNeed` | 深層ニーズ(本当のお困りごと) |
| `wants` | ウォンツ(どうなったら嬉しいか) |

## 2. UI配置(v1で未確定だった詳細)

既存の「新規顧客登録」フォームには`personalData`(個人データ)のみが存在し、`medicalHistory`・`familyData`は「顧客情報変更」の編集画面にしかない(初回登録時点では既往・家族データが分からないことが多いための既存の設計判断で、今回変更していない)。

このため、v1の「既往・家族データ・個人データと並べて3項目を追加する」という指示は、各画面に**既にある**フィールド群の並びに合わせる形で解釈した。

- **新規顧客登録フォーム**(`app/clients/new/page.tsx`): `personalData`の直後に3項目を追加
- **顧客情報変更(編集)画面**(`app/clients/[id]/edit/page.tsx`): `medicalHistory`・`familyData`・`personalData`の直後に3項目を追加
- **顧客詳細ページの基本情報カード**(`app/clients/[id]/page.tsx`): 「施術前に毎回確認」ボックス内の既往・家族データ・個人データ・健康実践状況(最新)の並びに、3項目を個人データの直後・健康実践状況の直前に追加(閲覧専用)

表示順はいずれも「顕在ニーズ→深層ニーズ→ウォンツ」で統一。
